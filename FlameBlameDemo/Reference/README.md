# Reference — кадри з трейлера Flame and Blame

Використовувати як орієнтир стилю (палітра, форма, настрій). Не копіювати, а відтворити власними асетами.

| Файл | Що брати |
|---|---|
| 01_hands_hydrant_hose | Руки першої особи: об'ємні рукавиці, світловідбивні смуги, жовтий рукав, червоний гідрант, теплий «закат» |
| 02_gloves_tools | Деталі рукавиць і куртки (смуги жовто-сірі, забруднення сажею), матеріали з м'яким затіненням |
| 03_living_room_fire | Головний референс сцени: вітальня, язики вогню на полицях/дивані, палітра дерева, дим під стелею |
| 04_hose_smoke_npc | Рукав у руках, щільний сірий дим, NPC-пожежник з великими очима |
| 05_charred_npc | Обвуглений NPC: темний, потріскана поверхня, білки очей, дим що йде вгору |
| 06_npc_character_design | Пропорції NPC: лиса велика голова, величезні очі, прості кінцівки, плоскі кольори |
| 07_cat_expression | Комічна міміка (виряченні очі, висунутий язик), мокрий вигляд |
| 08_debris_smoke_vfx | Уламки й клуби диму при руйнуванні: форма, кількість, швидкість |
| 09_fire_vfx_logs | Вогонь: форма язиків, кольори (жовтий→оранжевий→червоний), іскри, тліючі колоди |
| 10_electric_switch_warning | Червоний важіль, жовтий знак «небезпека — електрика», кабелі |
| 11_logo_ui_palette | Логотип, шрифт, палітра для HUD: червоно-оранжевий градієнт, чорні контури |
| 12_sunset_palette_group | Загальна кольорова схема «закату» (теплий оранжевий + бірюзове небо) |
| 13_night_lighting_fire | Нічна версія: вогонь як головне джерело світла, силуети, холодні тіні |

Ключові риси стилю: low-poly з округлими формами, насичена палітра, м'яке ступінчасте затінення, великі комічні очі, контраст теплого світла й холодних тіней, щільний стилізований дим.
