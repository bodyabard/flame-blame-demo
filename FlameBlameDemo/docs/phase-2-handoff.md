# Віха 2 — systems and chaos

## Готово

- Калюжі з пулу: з'являються від води на підлозі, поновлюються, випаровуються, проводять струм через суміжні калюжі. Жовтий колір означає небезпеку.
- Перерізаний кабель і пул іскор; незалежні cooldown ударів по гравцю/NPC, відкидання, тряска та червоний спалах.
- Два NPC з очима: паніка біля вогню, вода, струм, обвуглення; процедурне погойдування.
- Рухомі предмети, поштовхи струменя/рукава, обмежена початковою вартістю шкода майну.
- Observer-рахунок, pooled-повідомлення українською, таймер, результат, Command-перезапуск сцени.
- Рукав зберігає спіраль на старті й зіткнення з підлогою/предметами без стін/стелі.

## Налаштування

`Assets/_Project/Settings/ChaosSettings.asset`: 105 с, ліміт $10000, мінімум 12 с до дострокового завершення, 3 с без вогню, до 24 калюж на 22 с, cooldown удару 2 с. NPC, кабель, вартість предметів та HUD мають власні серіалізовані параметри.

Бюджет за стандартними шаблонами: jet 400 + flame 16×20 + steam 6×12 + splash 8×10 + spark 4×8 = 904 частинки. Пули ефектів мають жорсткі верхні межі; запит понад бюджет пропускається, калюжі/написи перевикористовують слот.

`Tools/FlameBlame/Upgrade Main to Phase 2` оновлює фазу 2 без перебудови кімнати: її об'єкти належать кореню `Phase2`. `Build Greybox` будує кімнату заново й також додає фазу 2. Main уже оновлена, повторно запускати меню не потрібно.

## Перевірено

- Unity 6000.3.24f1: компіляція runtime/editor, upgrade та збереження Main у batch mode.
- 19 EditMode-тестів: попередня логіка вогню/тиску/рукава та мінімальні перевірки ledger, round, контакту калюж і станів NPC.
- Повторний прогін у робочому проєкті: 19/19; локальний звіт `Logs/phase2-results.xml`. Оновлення Main також повторно виконано в робочому проєкті.
- Одноразовий smoke у копії проєкту: запуск Main → вода біля кабелю → NpcShocked → Washed → UI збитків → Result → кнопка Again → новий ledger і два NPC. Цей smoke не перевіряє художню якість або WebGL FPS.
- Перший smoke зупинила помилка індексатора `UnityEditor.Search.SearchDatabase` у новій тестовій копії; повторний запуск відокремлював цю editor-only помилку від runtime-помилок гри.
- Незалежний read-only перегляд: блокуючих зауважень немає; пунктуацію шрифту та одиниці оцінювання фізичного удару виправлено.

## ЗРОБИ ВРУЧНУ

1. Відкрий Main і натисни Play. WASD, миша, ЛКМ; E кидає/підбирає брандспойт. Розпили воду на підлогу поруч із видимим кабелем у центрі кімнати.
2. Змий NPC у жовту калюжу, перевір його реакцію та рахунок; зайди в калюжу сам і перевір спалах/відкидання.
3. Кинь увімкнений брандспойт біля дрібних предметів; перевір, чи рукав лягає на підлогу і збиває їх.
4. Загаси вогонь або дочекайся результату. Натисни «ЩЕ РАЗ»; перевір скидання NPC, калюж, рахунку й таймера.
5. Дай фідбек перед фазою 3: чи смішно, чи читається ланцюжок вода → калюжа → кабель → удар, що ламається або дратує. Окремо потрібен майбутній WebGL-білд/профілювання у Chrome.
