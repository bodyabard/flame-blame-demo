- Runtime values live in inspector settings. Default round: 105 seconds; end early only after an initial grace period and no active fire, or the damage cap.
- Use existing assembly definitions; add TMP/UI references rather than reorganizing assemblies.
- Execute directly in the current workspace as requested. No intermediate approval gates; stop at milestone 2.
