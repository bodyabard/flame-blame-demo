# Фаза 4 — WebGL-білд, стабільність, здача

Прочитай `CLAUDE.md`. Візуал і геймплей прийняті на віхі 3.

## Завдання
1. **Налаштування збірки:** `Tools/FlameBlame/Configure WebGL` — Brotli, Texture Compression, Managed Stripping Low, без data-caching проблем, розумний розмір канваса, `Run In Background`. Якщо потрібно, Editor-скрипт `Tools/FlameBlame/Build WebGL` (batch-build) і інструкція запуску локально (`python -m http.server` або Unity Build&Run).
2. **Стабільність:** пройдись по коду на алокації в Update, `Shader.Find`, відсутні пули, помилки в консолі, null-ref при рестарті сцени, витоки подій (відписки Observer), `OnDestroy`. Виправ без рефакторингу архітектури.
3. **Перфоманс-бюджет:** авто-лімітер частинок/активних вогнів (якщо FPS падає — зменшує емісію), відсікання далеких ефектів.
4. **Запасний exe:** конфіг Windows-білда (одна команда меню).
5. **Фінальний прохід:** README для суддів (керування, суть фічі, як запускати), `AI_LOG.md` у вигляді 2 речень «де й як використано AI і чому ця фіча».
6. **Сценарій відео ≤5 хв** (`VIDEO_SCRIPT.md`) у розмовному стилі, українською, по таймінгах: 0:00 хук (що це) → механіка за 30 с → як працює система (вода/вогонь/електрика/рукав) → рішення, які ухвалили → як використано AI (з `AI_LOG.md`) → що лишилось за кадром і що зробив би далі → фінальний «хаос». Субтитри можна.
